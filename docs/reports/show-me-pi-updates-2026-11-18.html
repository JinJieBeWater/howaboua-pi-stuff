Pi 扩展更新日志

Pi 本体已是 1.5.2。通知列出 5 个 npm 包；其中 3 个新版声明了同一个 conversion peer 下限。先看这次 fork 更新带来了什么。

本地 fork

pi-codex-conversion · 5.0.0 → 5.0.1

新增 VM Code，变量可在同一对话复用，支持顶层 await、内存上限和强制取消。新增 GPT-6.2 Sol、Astra、推理设置和费用估算。TS 模式升级至 tsrs 0.25 和 TypeScript 7.1 beta。

工具图片只显示一次并遵循可见性设置，切换详情可复用预览。缓存日志能定位提示词变化而不记录正文。工具示例放宽了对调用语法的要求。

pi-agent-comms · 0.0.2 → 0.0.3

new_context({resume:false}) 可在回复后开启新上下文并停下。Code 和 Notebook 可在同一段代码中等待笔记保存后切换上下文。短 UUID 查找失败会给出重试方法。

调整长期任务的角色预设指引、Notes／History／Board 示例，以及新建 Notes 白名单的模型。

pi-shepherdr · 1.0.1 → 1.0.2

修复崩溃重启后 worker 启动失败、完成报告丢失，以及独立 Bun 版 Pi 启动 agent 和聚焦窗口的问题。发件人显示机器、完整地址和终端。空闲 worker 的空回合不再发送完成通知。

交接指引减少重复通知，新建通用 profile 使用 GPT-6.2 Sol。

pi-browser · 0.0.13

版本号相同。上游 manifest 已把可选 conversion peer 下限调至 5.0.1。

随 conversion 对齐的 npm 包

pi-ask · 0.0.19 → 0.0.20

帮助现在明确 handoff 接受布尔值。

pi-codex-web-run · 0.0.10 → 0.0.11

要求 Pi 1.5+。更新提醒改用 Pi 原生机制，遵循 collapseChangelog；参数定义从 TypeBox 切到 Pi 原生 schema。搜索示例不再指定 await 写法。

pi-codex-imagegen · 0.0.14 → 0.0.15

生成的图片在普通和嵌套工具结果中都只显示一次。帮助不再指定 await 或 .then()。

可独立更新的 npm 包

pi-permission-system · 42.0.0 → 42.0.2

42.0.1 补全权限术语表和策略通道文档。42.0.2 修复权限匹配，子 agent 转发 Bash 命令时，父端会按命令的不同拼写匹配策略。

查看两个补丁的变更

pi-web-access · 0.47.0 → 0.48.0

新增显式选择的 SpecStream、Autom 和 cloro 搜索服务。可用支持图像输入的模型回答视频问题，无需 Gemini 密钥。第一页正文抽取不全时会尝试补全，搜索服务超时会切到下一家。修复 DuckDuckGo 连续搜索易被封和首条消息前切换模型时工具加载策略未更新的问题。
