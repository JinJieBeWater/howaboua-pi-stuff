# Pi 启动加载优化

当前补丁按最小改原则收敛，只保留三个加载优化：

- Shepherdr：用现有 Bun 构建器将包内模块合并为 Node ESM，运行逻辑保持原样。
- Notes：同样打包，并保留独立 context-sharing 入口、类型信息和原资源路径。
- Browser：两个内部文件延迟加载执行后端，help 无须加载后端；工具接口保持原样。

Pi 继续运行在 Node 上，Bun 只用于构建。SDK 和扩展间依赖保持 external；打包时保留原文件位置作为资源 URL 的基准。

本轮 Codex 设置/报告拆分、SDK 注入和 Board 新发现接口均已撤回。Board 与 Shepherdr 保持原有接口和依赖关系。改动收敛为 9 个 tracked 文件及 4 个新文件，运行时源码仅改 Browser 两个文件；其余为构建脚本、包配置、changeset 和本文档。

## 测量

2026-11-01，实际 Pi 1.4.0 bundled Node CLI，使用官方 PI_STARTUP_BENCHMARK/PI_TIMING 和 --offline --no-session。隔离 agent 目录，其他扩展列表保持相同，仅替换上述三个候选包；没有请求模型或改动日常配置。候选使用真实 tarball/node_modules 布局。

先各运行一次预热并排除，再按基线/候选交错测量各 5 次。以下均扣除官方固定的 150 ms 等待，近似 TUI 初始化完成时间：

| 指标 | 已安装基线 | 最小补丁候选 |

| 中位数 | 4,537.6 ms | 2,467.4 ms |
| 范围 | 4,059.6–5,476.0 ms | 1,900.6–2,784.9 ms |

本轮中位数减少 2,070.2 ms，约 46%。环境存在波动，绝对时间不与之前较大补丁的轮次直接横比。
